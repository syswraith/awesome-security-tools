# Contributing

Thanks for helping make this list better! This repository collects useful tools for CTFs, reverse engineering, and problem solving.

## What to contribute

Any useful, publicly accessible tool that fits the list.

Submit one tool per pull request.

## How to contribute

1. Fork this repository.
2. Create a new branch, for example `add-tool-name`.
3. Add a single row to the table in `README.md` with the tool's **name**, **link**, and **description**.
4. Commit your change and push the branch to your fork.
5. Open a pull request against this repository.

Your pull request should include:

- **Name** of the tool.
- **Link** to the tool.
- **Description** of what the tool does and why it is useful.

## Entry format

Use this format for the new table row:

```markdown
| [Tool Name](https://example.com/) | Short description of what it does and why it's useful. |
```

## Guidelines

- The tool must be useful and publicly accessible.
- The link must work.
- Keep the description concise, ideally one or two sentences.
- Submit one tool per pull request.
- Preserve the existing table formatting and alignment.
